# Group Project — Backend Web Scraper API

This repository contains the backend component of a group project completed as part of the **Computer Programming program at Algonquin College (Ottawa, Canada)**.

The project was developed for a real client and focused on backend development only. Due to confidentiality and academic restrictions, full documentation and certain implementation details cannot be publicly shared.

---

## 📌 Project Overview

The objective of this project was to build a **backend service that aggregates product availability data from nearby physical (in-person) stores**.  

The system allows users to find required items without having to manually browse multiple store websites, helping them locate products available locally.

Because this was a **large-scale, multi-component project**, the team was tasked specifically with developing the **backend logic and APIs**. No user interface was required or implemented as part of this scope.

---

## 🛠 Technical Scope

- Backend-only application (no front-end / UI)
- Interaction with the system is performed through **API endpoints**
- Focus on data collection, processing, and structured output
- Designed to support integration with a future front-end application
